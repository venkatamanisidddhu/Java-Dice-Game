# Java Swing Dice Game

A multiplayer desktop dice game built with Java, demonstrating Object-Oriented Programming principles and GUI development with the Swing toolkit.

* Built a multiplayer desktop Dice Game using **Java** and the **Swing toolkit**, showcasing strong **Object-Oriented Programming (OOP)** and **GUI** development skills.
* Designed the application using a modular **3-layer architecture** to clearly separate core logic in the `GameEngine` from the event-driven UI, significantly improving code maintainability.
* Engineered a responsive user experience by implementing dynamic setup dialogs using `JOptionPane` and a real-time game log that provided players with instant feedback on every round.

## How to Run the Project

1.  **Compile the source files:**
    Open a terminal in the project directory and run the following command:
    ```bash
    javac *.java
    ```

2.  **Run the application:**
    After compiling, run this command to start the game:
    ```bash
    java DiceGameUI
    ```
    *(The main method is located in the `DiceGameUI` class).*
